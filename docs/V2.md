# HanziGo V2 — đọc và học

Phạm vi: kết nối cấu hình Firebase được cung cấp; mở rộng thư viện lên 20 truyện và 200 mục từ; bàn biên tập nội dung; ôn theo truyện và tìm từ đã lưu. Giữ ID của 5 truyện V1 để bảo toàn tiến độ. Nội dung mới là bản nháp do AI biên soạn, chưa được người đọc tiếng Trung duyệt.

1. Firebase: cấu hình local và project mặc định; kiểm tra trạng thái kết nối thật. Không triển khai production tự động. Analytics chưa thu thập sự kiện.
2. Nội dung: thêm 15 truyện nguyên bản với Hanzi/Pinyin/dịch Việt, 10 mục từ, 3 câu hỏi, câu xếp từ mỗi truyện. Kiểm tra schema, IDs, mapping và tone.
3. Biên tập: route admin bảo vệ bởi guard hiện có; lưu nháp riêng trên thiết bị, nhập/xuất JSON, báo lỗi rõ vị trí, preview cùng thành phần reader. Xuất toàn bộ thư viện để cập nhật seed qua pipeline; không tự phát hành khi lưu nháp. Form chỉnh từng phần, JSON để thêm/bớt cấu trúc.
4. Học: tìm kiếm không dấu; chủ đề không trùng; lọc ôn theo truyện, tìm từ đã lưu, thêm bộ từ từng truyện; interval thực tế trên nút đánh giá. Liên kết reader sang bộ ôn đúng truyện.
5. Kiểm chứng: unit tests, content validation, build và browser desktop/mobile. Cập nhật README và hướng dẫn Firebase còn thiếu nếu có.

Đồng bộ tiến độ giữa thiết bị, mở khóa thư bằng tiến độ server tin cậy, push và audio thu sẵn vẫn cần giai đoạn riêng. Không dùng tiến độ local như bằng chứng bảo mật.

Đã hoàn thành các mục 1–5. 49 unit test và 14 rule test đạt; build đạt. Trạng thái cloud cuối: Anonymous Auth cấp UID thành công; Firestore API trả `403 SERVICE_DISABLED`. Cần tạo Firestore Database/bật API, bật provider admin và thiết lập allowlist/rules/indexes. Chi tiết kiểm chứng tại QA.md.
